# 5 · Living Ecosystem Landing (GitHub Pages preview)

Isolated bilingual, noindex, public-safe redesign. **Not** production. Original snail/mountain SVG and minute demo are byte-for-byte retained from the approved landing preview.

- RU: https://preview-5.peaceful-world.org/landing-ecosystem/ru/
- EN: https://preview-5.peaceful-world.org/landing-ecosystem/en/

## Data policy

The landing reads **published application data** from:
- https://5.peaceful-world.org/web-vnext/roadmap.json
- https://5.peaceful-world.org/locales/index.json

If runtime CORS/network access is unavailable, it reads the snapshot in `data/*-fallback.json`. It never turns unconfirmed ideas into released practices. Current three onboarding cards remain evergreen; the future catalogue renders `status` only when the app source explicitly provides it, otherwise `planned`. New languages populate from the released locale registry; proposed languages from the app roadmap. Planned does not mean scheduled. No payment, email capture, tracking or cookies in this preview.

The remaining standalone visuals (`base.css`, `production.css`, `legacy-experience.css`, `experience.js`) are copies of the approved website preview; scripts for the real app are untouched. The hero phone image is the previously approved **illustrative** image, not a new screenshot.

**Important:** this is a preview presentation; production migration needs a new bounded website-lab PR, privacy/SEO review, and explicit owner approval. No native builds.
